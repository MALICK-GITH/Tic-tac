# Tic Tac Toe Predictor

Base Next.js en français pour un site de pronostic de matchs virtuels Tic Tac Toe.

## Fonctionnalités

- Accueil type live feed avec cartes horizontales
- Page détail par match avec grille reconstruite
- Logique de pronostic locale, simple à remplacer par un backend
- Interface sombre inspirée d’un dashboard de paris

## Lancer le projet

```bash
npm install
npm run dev
```
